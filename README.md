# حقيبة الموجهات التفاعلية للثانوية العامة المصرية (الصف الثالث الثانوي)

هذا المستودع منظم حسب **المواد العلمية**؛ حيث يضم كل مجلد خاص بمادة دراسية كافة موجهاتها التعليمية ومهاراتها ومراجعها الرسمية، بالإضافة إلى مجلد عام للإرشادات المشتركة.

تعتمد الموجهات على **الحوار التوجيهي خطوة بخطوة**، حيث يسأل المعلم عن اسم الطالب/الطالبة والشعبة في بداية المحادثة، ثم يرشده بالأسئلة المتدرجة لحل المسائل وفهم المفاهيم دون إعطاء الإجابات الجاهزة.

## 🛠️ كيفية الاستخدام السريع:

1. **دليل الطالب**:
   - ابدأ بقراءة [`general/student_guide.md`](./general/student_guide.md) للتعرف على طريقة الحوار والتفاعل خطوة بخطوة مع الموجه.
2. **تثبيت الموجه في المنصة المفضلة**:
   - راجع [`general/how_to_install.md`](./general/how_to_install.md) لإنشاء النموذج المخصص في ChatGPT أو Gemini أو Claude، ثم انسخ ملف `prompt.md` الخاص بالمادة التي تود مذاكرتها (مثل [`physics/prompt.md`](./physics/prompt.md)).
3. **تجنب الأخطاء الشائعة**:
   - اطلع على [`general/common_traps.md`](./general/common_traps.md) لمراجعة النقاط الدقيقة التي تتكرر حولها الاستفسارات في امتحانات الثانوية العامة.
